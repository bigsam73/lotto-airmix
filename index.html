Engine notes · 64k-intro techniques
  • Deterministic fixed timestep dt = 1/240 s. Frame rate and speed multiplier only change how many steps run per frame, never the outcome.
  • Single seed: the loading order is hashed with 32-bit FNV-1a and seeds every procedural element (loading micro-offsets, turbulence field).
  • Integer-hash value noise builds the 3D turbulence field. No sin/cos/exp; only imul, basic IEEE arithmetic and sqrt, so results replay identically across browsers.
  • Air field = central rising jet (rational-function core) + floor inflow + noise turbulence; balls follow it through linear drag a = k(u − v).
  • Collisions: sphere–sphere impulses (e = 0.55) with position correction, glass shell, both faces of the funnel, throat wall, gate lid. No artificial suction: balls leave through air drag and contacts alone. With 45 balls, O(n²) is plenty.
  • Procedural assets: ball textures are drawn on a canvas at runtime, all geometry is primitives. Zero external assets; Three.js is the only dependency.
