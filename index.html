엔진 노트 · 64k 인트로 기법
  • 결정론적 고정 타임스텝 dt = 1/240 s. 프레임레이트와 속도 배율은 스텝 수만 바꾸고 결과엔 영향이 없습니다.
  • 단일 시드: 투입 순서 배열을 FNV-1a 32비트로 해시해 모든 절차적 요소(투입 미세 오프셋, 난류장)의 시드로 씁니다.
  • 정수 해시 value noise로 3D 난류장을 만듭니다. sin/cos/exp를 쓰지 않고 imul·IEEE 기본 연산·sqrt만 사용해 재현성을 확보했습니다.
  • 공기장 = 중앙 상승 제트(유리함수 코어) + 바닥 유입류 + 노이즈 난류, 공은 선형 드래그 a = k(u − v)로 끌려갑니다.
  • 충돌: 구–구 임펄스(e = 0.55) + 위치 보정, 유리구 내벽, 흡입 튜브 벽, 게이트 덮개. 45개라 O(n²)로 충분합니다.
  • 프로시저럴 에셋: 번호공 텍스처는 실행 시 캔버스로 생성, 지오메트리는 모두 원시 도형. 외부 에셋 0개, 렌더러만 Three.js.
